As pastas de atividades mantem os arquivos entregues pelo aluno e, quando disponivel, o enunciado oficial da atividade. As pastas de aulas concentram os materiais fornecidos em sala. Os documentos de ABP foram mantidos separados para facilitar a consulta durante as sprints.

O projeto ABP da disciplina utiliza requisitos e sprints para aplicar, de forma incremental, os conceitos de Banco de Dados Relacional em um contexto pratico.

Os documentos relacionados ao projeto estao organizados na pasta [Requisitos-ABP](Requisitos-ABP).
