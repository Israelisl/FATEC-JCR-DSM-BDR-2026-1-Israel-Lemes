# P1 - Conteudos

Materiais relacionados a primeira etapa da disciplina de Banco de Dados Relacional.

## Organizacao

| Pasta | Descricao |
| --- | --- |
| [Aulas](Aulas) | Materiais de apoio utilizados nas aulas da P1. |
| [Atividades](Atividades) | Enunciados e entregas individuais das atividades da P1. |

## Foco da etapa

Na P1, o repositorio registra os primeiros fundamentos da disciplina: introducao a bancos relacionais, modelagem, diagramas, organizacao de tabelas, relacionamentos e praticas iniciais de manipulacao de dados.

## Resumo das atividades

| Atividade | Descricao |
| --- | --- |
| [Aula 01](Atividades/Atividade-Aula01) | Material inicial da disciplina e orientacoes de organizacao. |
| [Aula 02](Atividades/Atividade-Aula02) | Criacao de banco relacional, tabela de focos de calor, insercao de registros e consulta dos dados. |
| [Aula 03](Atividades/Atividade-Aula03) | Modelagem DER para sistema de aluguel de carros, com entidades, atributos, chaves e relacionamentos. |
| [Aula 04](Atividades/Atividade-Aula04) | Modelagem do banco `clima_alerta`, com tabelas normalizadas, relacionamentos e tabela auxiliar. |
| [Aula 05](Atividades/Atividade-Aula05) | Popular o banco `clima_alerta` e consultar dados com filtros e ordenacao. |
| [Aula 06](Atividades/Atividade-Aula06) | Insercoes em tabelas relacionadas, consultas ordenadas, limite de resultados e uso de constraints. |
| [Aula 07](Atividades/Atividade-Aula07) | Funcoes de agregacao, agrupamentos e indicadores sobre usuarios, eventos e localizacoes. |
| [Aula 08](Atividades/Atividade-Aula08) | Sistema bancario com clientes, contas, transacoes e consultas usando juncoes. |
| [Aula 09](Atividades/Atividade-Aula09) | Juncoes entre eventos, tipos e localizacoes, comparando INNER, LEFT e RIGHT JOIN. |
| [Aula 10](Atividades/Atividade-Aula10) | Relatorios avancados no banco `biblioteca`, integrando editoras, autores, livros e emprestimos. |
| [Revisao](Atividades/Atividade-Revisao) | Material de revisao e gabarito para preparacao da P1. |
